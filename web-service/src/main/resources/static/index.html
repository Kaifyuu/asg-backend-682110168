🎲 DataDuel

The left card is always revealed. Guess whether the hidden card on the right is Higher, Lower, or Equal. Every guess submits a real Comparison to the backend, which computes the true answer server-side. Each card shows two corner numbers: its rank in this deck and its rank across every card dealt this run — remembering both rewards good memory and lets you calculate better picks. Decks shrink: when a deck runs out, the number of cards you got right in it becomes the size of the next deck; the more cards you have left and the more decks you've cleared, the bigger each correct guess pays out. Get 0 right and it's game over — start fresh with a new 20-card deck. Keys: ↑/W Higher · ↓/S Lower · E Equal · Space/Enter Next card.
